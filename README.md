# MingYue的个人博客
MingYue 个人博客，基于 SpringBoot 2.7 + Vue2 搭建，支持文章管理、标签分类、全文搜索和评论系统，是一个轻量化的个人知识库博客。

## 关于作者

博客演示地址：https://www.wuliqun.cn
邮箱地址：superstarliqun@gmail.com
## 技术栈
  - 后端：SpringBoot 2.7, MySQL, Redis
  - 前端：Vue2, ElementUI
  - 搜索：ElasticSearch
  - 构建工具：Maven, npm

## 项目接口
```bash
backend/   # SpringBoot 后端代码
frontend/  # Vue2 前端代码
docs/      # 项目文档、截图等
```
